# Design references

The root HTML mockups and original `requirements.md` were moved to `legacy/` during the monorepo import. They describe the earlier project manager design. The ten HTML files matched the copies in `scrum-app-ui/mockups/` at import time; both sets were preserved so no original design artifact was discarded.

`scrum-app-ui/mockups/` also includes `assignee-dashboard/` with role selection, enrollment, sprint selection, dashboard, tasks, and timeline examples. Its README describes the static mockups, not the current Angular/API implementation.

Open the HTML files directly in a browser to inspect their design. Some reference CDN assets and use mock data or demo credentials. Follow [the source-derived specification](../project-specification.md) and [known gaps](../known-gaps.md) for application behavior. Legacy stack/version/status statements should not override the manifests and code.
